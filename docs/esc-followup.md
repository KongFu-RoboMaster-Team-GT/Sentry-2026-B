# 回中抖动与C620瞬态指示跟进

现场反馈：正常按ID闪绿灯，摩擦轮运行时，摩擦轮或底盘ID4偶发一两下蓝/红指示后恢复。用户确认摩擦轮在上板CAN1、底盘在下板CAN2、两板仅CAN1互连；全车共用标称24V电池。尚无完整重复灯码、故障时电调端电压波形或CAN记录，不能据颜色单独确认根因。

## 已修正的停车遗漏

上一版`chassis_can_release()`没有保存“已经释放”的状态，轮速重新超过阈值就又闭环制动；无法降到阈值时则无限保持制动。这是确认的软件遗漏，可能解释部分回中抖动，不是对现场全部抖动的根因证明。

现增加停车释放保持状态，只有新的非零运动请求能重新启用；目标速度归零后最多继续制动300ms，到时退出并清积分。回中保持时即使反馈受到扰动，指令仍为零。跟随和小陀螺仍按原开关工作：摇杆回中不代表旋转请求为零。若`idle_latched=0`，同时检查`chassis_motion.gimbal_target_vx/vy`、`chassis_target_omega`、`theta`、原始`ch0/ch1`和跟随/陀螺开关。

新增回归在修复前明确失败；修复后实际任务验证了释放后收到200rpm扰动仍保持零指令，并验证制动超时不会每轮重复累计。

## 灯色应按具体节奏确认

[DJI C620官方说明书](https://rm-static.djicdn.com/tem/17348/RoboMaster%20C620%20Brushless%20DC%20Motor%20Speed%20Controller%20V1.01.pdf#page=29)第29–30页说明：红灯每组2次指向三相接线、3次指向7针线的位置数据、4次指向温度异常；红灯1次的过压检测限于上电自检。该版说明书未列“蓝灯报警”。瞬闪且马上恢复不一定构成完整灯码，不能据此判断欠压、CAN丢包或过流。

说明书中的红灯异常会停止电调输出，因此“电机卡住”可能是电调保护后失去输出，也可能是机械阻滞引起负载变化，因果尚未确认。不能通过继续加大PID输出处理未知报警。

## 分开CAN后需要验证的共同路径

源码上发射命令为上板CAN1的0x200，底盘命令为下板CAN2的0x200。CAN线路确实分开时，同一个报文ID跨两条物理总线不构成冲突，摩擦轮命令也不会经现有板间协议转成底盘ID4电流。不要仅因两者都用0x200就改电调ID或协议。

摩擦轮启停与不同总线上的电调异常同步，应优先验证共享供电接头、供电回流和电机线束的抗干扰。电池标称24V不等于电调XT30端没有瞬态跌落或抬升；这是待验证方向，未证明实际欠压/过压。若确实是红灯3次，更应优先检查7针线及插头，而不是归因于CAN。

当前摩擦轮目标在启动时一步切为±600rad/s，PID的D项使用误差差分；从静止的首次目标阶跃单独产生约1200的D项（映射前），远高于±10限幅。它证明启动输出会饱和，并不证明这就是电调指示的根因。本次未盲改摩擦轮增益、转速、电流上限，也未更改C620固件。

## 新增上板只读诊断

| 字段 | 含义 |
|---|---|
| `board_diag.motor_can1_rx_count[0/1/2/5]` | 摩擦轮1/2、拨弹、pitch的有效CAN反馈累计数 |
| `board_diag.motor_can1_age_ms[0/1/2/5]` | 各电机反馈年龄，每毫秒板间任务更新；从未收到为0xFFFFFFFF |
| `board_diag.motor_can1_last_tick_ms[...]` | 对应电机最近反馈时刻 |
| `board_diag.shooter_tx_queued_count/shooter_tx_fail_count` | 发射0x200帧入队成功/失败次数；入队不代表电调收到 |
| `shooter_control.friction_omega[2]` | 两路摩擦轮实际电机轴速度，rad/s |
| `shooter_control.friction_output[2]` | 发射任务计算输出；通信/校准门控仍可能令最终发送值归零 |
| `board_diag.can1`（上板）、`board_diag.can2`（下板） | 原有Bus-Off、恢复阶段和错误快照 |
| `lower_diag.feedback_age_ms[3]` | 底盘ID4反馈年龄 |
| `lower_diag.chassis_command[3]` | 底盘ID4最终请求发送指令 |

电机反馈计数只统计电机报文，板间心跳不能掩盖摩擦轮反馈中断。新增字段只用于诊断，不增加上板电机使能条件、不改变射击控制。原始电机反馈不包含本轮查询的完整LED灯码。

## 建议现场顺序

1. 电机卡住/报警时先停止摩擦轮输出，避免持续对堵转电机施加指令。断电检查ID4及摩擦轮的7针插头、同规格线缆、三相接头和机械自由度，确认三相线颜色配对。替换线缆测试时保持每台电机的三相和7针对应关系。
2. 架空底盘、关闭跟随/小陀螺并移除弹丸，先验证回中`idle_latched=1`时四轮指令持续为零，再观察摩擦轮启动时ID4是否还出现指示。该步骤可区分底盘主动纠偏输出与外部共同影响。
3. 同步记录两板诊断和电调灯的完整重复周期；用示波器在异常C620供电入口捕获摩擦轮启停时的电压与回流变化，单次电池电压读数不能排除短瞬态。
4. 若上板摩擦轮反馈年龄增长或发送失败/Bus-Off计数增长，查相应CAN链路；若反馈仍连续但速度骤降并有明确红灯异常，按具体灯码检查电机侧连接、温度与电调。若两边同时异常而CAN计数正常，优先检查共同供电与线束干扰。

停车保持需要更新LOWER；要使用上板新增诊断还需更新UPPER。两者均已生成在`firmware/`，协议3不变；未代用户烧录。SINGLE 21、UPPER 4493、UPPER_GUARD 3502、LOWER 1104个断言通过，上下板Keil均0错误、0警告；这些结果不能证明硬件灯闪问题已修复。
